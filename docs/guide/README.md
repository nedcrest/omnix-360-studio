# The guide

Omnix is a home-video editor for 360 and ordinary footage; Dailix is its
contact sheet, where a trip's footage is looked through and chosen
before the edit. This guide covers both.

- **New here?** [Install them and run them for the first
  time](install.md).
- **Then the tutorial**: one short trip, from its clips to a
  finished film, in two parts: [choosing in Dailix](tutorial-1-dailix.md),
  then [editing in Omnix](tutorial-2-omnix.md).
- How-to pages, a task each, the reference (keys, panels, settings,
  commands) and the explanations follow.

The tutorial uses a trip of six short clips. Any trip of your own works
the same way.
